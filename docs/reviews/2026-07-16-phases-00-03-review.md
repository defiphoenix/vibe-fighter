## Findings (none blocking; address in Phase 04+ when touching the sim)

1. **Medium — bodies escape stage during `roundEnd`/`matchEnd`.** `settleBodies` (`world.ts:118-121`)
   runs `integrate()` only — no `clampX`/`resolveSpatial`. A KO'd fighter (airborne, `vx=±240`) or a
   timeout-win walker (`vx=±220`, grounded/non-stun so no friction) slides off-screen for the
   settle window. Cosmetic (re-fixed by next `resetRound`). Fix: `clampX` inside `settleBodies`.
2. **Low-Med — test gaps** for shipped features: Enter-rematch `World.restart()` (`world.ts:175-181`),
   timeout win/draw (`decrementClock`, `world.ts:153-160`), double-KO draw (`world.ts:148`),
   right-wall corner (only left-wall `MIN_X` branch tested — `regression.test.ts:24-35`).
3. **Low — dead/stale method** `Fighter.hasActiveHit()` (`fighter.ts:228-231`), unused, duplicates
   `resolveCombat` logic. Remove or wire.
4. **Low — input latch cleared by non-actionable ticks.** `MatchScene.ts:101-102` clears the edge
   latch on any `ticks>0`, but `tick()` returns early (consumes nothing) during intro/roundEnd/
   matchEnd/hitstop. An attack/jump edge buffered on the final intro tick can drop.
5. **Nit — facing/depth freeze during settle phases** (`world.ts:94-95` run only in fight branch)
   while `settleBodies` still moves bodies. Fold into fix #1.
