## What differed from the recipe
The recipe assumes **pre-bundled spritesheets** that do not exist in this repo, and names Codex
`$imagegen` for static art (not wired — same gap recorded for Phase 03). So Phase 02 stood up the
pipeline with a **deterministic placeholder sheet** generated by a stdlib PNG writer
([`scripts/gen-placeholder-sheet.mjs`](../../scripts/gen-placeholder-sheet.mjs), `npm run gen:placeholder`)
instead of a real art asset. Real per-state character sheets land in Phase 09; this phase only proves
the load→anim→anchor path end to end.

## Acceptance criteria

### 1. One fighter animation loads and plays in a scene (replaces a box) — PASS
The pipeline is consistent end to end (verified by the review's "Phase-02 pipeline — consistent"
section and re-checked here):

| Stage | Artifact | Verified |
|---|---|---|
| Generate | [`scripts/gen-placeholder-sheet.mjs`](../../scripts/gen-placeholder-sheet.mjs) | writes `public/sprites/test/brawler-idle.png`, PNG header **1280×256 = 4×320×256** (4 frames), self-checked in-script |

| Schema | [`public/configs/sprite-schema.md`](../../public/configs/sprite-schema.md) | frame size, fps, key, feet anchor all agree with the above |

A Playwright acceptance spec (`e2e/`) drives the render layer past the intro gate and asserts fighter
A renders as a sprite with **no debug box fill** (via the `__boxFills` DEV seam) — 2/2 green in the
review baseline.

### 2. Sprite anchor aligns with sim boxes under the `B` debug overlay — PASS
The sprite origin is `(0.5, 1)` — feet-centered ([`MatchScene.ts:64`](../../src/scenes/MatchScene.ts#L64)) —
matching the sim's box convention (`+y` up from the feet, `geometry.ts`) documented in
[`sprite-schema.md`](../../public/configs/sprite-schema.md). Position/mirror follow sim state
(`setPosition(f.x, f.y)`, `setFlipX(f.facing < 0)`), so the `B`-toggle hitbox overlay lines up with
the drawn sprite.

### 3. Every asset row in the manifest has a chosen source + license — PASS (for the shipped assets)
[asset-manifest.md](../asset-manifest.md) records provenance/licensing; the placeholder sheet is
marked as a locally generated stand-in. The full roster's real-art rows are due before Phase 09 per
the spec, and the art phases 04–07 (Higgsfield CLI) fill them.
